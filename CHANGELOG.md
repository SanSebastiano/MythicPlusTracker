# Changelog

All notable changes to MythicPlusTracker are documented here.

## [1.0.0] - xxxx-xx-xx

### Added
- Initial release of MythicPlusTracker for World of Warcraft: Midnight
- Dungeon table with sortable columns (name, best time, key level, score)
- Best-time delta tooltip showing time above/below the limit
- Sidebar with M+ score, affixes, keystone, weekly vault, and currencies
- Omnium Folio trait node display with interactive selection popup
- Localization support (en-US, de-DE)
